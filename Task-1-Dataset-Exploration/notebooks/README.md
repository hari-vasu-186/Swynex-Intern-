# Python Notebooks

This folder contains Jupyter notebooks created for the SWYNEX internship.

## Task 1 – Dataset Exploration

### Notebook Name
`Task1_Exploration.ipynb`

### Description
This notebook performs exploratory data analysis and preprocessing on the Titanic dataset.

### Operations Performed
1. Importing Python libraries.
2. Loading the Titanic CSV dataset.
3. Exploring rows, columns and data types.
4. Generating statistical summaries.
5. Identifying missing values and duplicates.
6. Creating data visualizations.
7. Cleaning and preprocessing the dataset.
8. Writing observations and conclusions.

## Environment
Google Colab / Jupyter Notebook

## Libraries
Pandas, NumPy, Matplotlib and Seaborn.
